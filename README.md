# talk.01

**Portable voice interface / 便携式语音输入设备**

An open-source, wired USB microphone with programmable physical controls, inspired by retro industrial design. Built for everyday voice input and occasional recording.

## Why
A small personal project: make voice input as satisfying as using a mechanical keyboard or a vintage radio. Pick it up, hold the lever, speak, release; put it on the desk and use it as a normal microphone. Affordable, portable, and genuinely useful rather than a novelty.

## Product direction
- USB-C wired, bus powered; standard USB microphone and programmable keyboard controls.
- Handheld pager / radio-inspired form, tactile side lever, restrained graphics and status indicators.
- Integrated rear folding kickstand, no separate dock required.
- Default interaction: hold Alt for WeChat Input, release Alt to stop; double tap to send (subject to safe gesture design). Continuous microphone mode for recording, meetings and podcasts.
- Clear natural voice recording, not studio-grade; no compulsory effects or aggressive processing.
- Development-board prototype first, custom PCB only if useful. 3D-printable enclosure.
- No battery, wireless, built-in AI or complex DSP in v0.1.

## Status
Concept and research only. No hardware, firmware, sound quality or CAD has been validated yet.
